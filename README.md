# Football League Prediction | لیگ پیش‌بینی فوتبال

## Features | امکانات
- Register 6 Football Teams | ثبت ۶ تیم فوتبال
- Register 5 Players | ثبت ۵ بازیکن
- Random Match Scheduling | قرعه‌کشی تصادفی مسابقات
- 5 Weekly Match Rounds | برگزاری ۵ هفته مسابقه
- Random Match Results | تولید نتایج تصادفی
- Match Prediction System | سیستم پیش‌بینی مسابقات
- Automatic Point Calculation | محاسبه خودکار امتیازات
- Weekly Ranking | رتبه‌بندی هفتگی بازیکنان
- Final Leaderboard | جدول امتیازات نهایی

## Scoring System | سیستم امتیازدهی

- Exact Score: +10 Points
- Incorrect Exact Score: -2 Points
- Correct Goal Difference: +7 Points
- Incorrect Goal Difference: -2 Points
- Correct Winner Prediction: +5 Points
- Incorrect Winner Prediction: -2 Points

## Technologies | تکنولوژی‌ها
- Python
- Random
- Time

No additional libraries are required.
